daftar - Your personal resources library website that you can add stuff you feel is worth noting!
It stores every data in browser's localstorage, your data never leaves your device.

- You can add any type of resource by pasting it's link and categorizing it according to it's type.
- Later view those resources based on their flags, like favourites, archived, etc.
- A nice pleasant theme, without very flashy components. As this is one of my initial web dev projects, I tried to use as minimal as possible things.
- Some noteworthy Javascript concepts used in this was: localStorage, event delegation, and stuff like Object assign for editing the resource.

Demo link: https://aryatajne28.github.io/daftar/pages/
